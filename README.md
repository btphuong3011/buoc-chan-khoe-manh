# Sàng Lọc Bàn Chân Tiểu Đường

[Mở nguyên mẫu trên GitHub Pages](https://btphuong3011.github.io/sang-loc-ban-chan-tieu-duong/)

Mở `index.html` bằng trình duyệt. Nguyên mẫu chạy bằng HTML, CSS và JavaScript, với ba ca hư cấu để minh họa luồng ghi nhận, đánh giá và in phiếu A4.

Bấm một điểm trên sơ đồ rồi chọn phản hồi. Ghi dữ kiện chuyên môn ở bước **Đánh giá nguy cơ**. Bấm **Ca mới** để xóa dữ liệu của phiên. Dữ liệu chỉ nằm trong bộ nhớ trang.

Căn cứ của luồng minh họa gồm [Bảng 1 IWGDF 2023](https://iwgdfguidelines.org/wp-content/uploads/2023/07/IWGDF-2023-02-Prevention-Guideline.pdf), [Quyết định 1530/QĐ-BYT](https://ttytchuse.gialai.gov.vn/Document/Details.aspx?id=NjI%3D) và [NICE NG19, mục 1.4](https://www.nice.org.uk/guidance/ng19/chapter/recommendations#diabetic-foot-problems). Đánh giá và quyết định theo dõi thực tế thuộc nhân viên y tế.
